<h1>Способы запуска программы на Пионере Мини 2</h1>

<p>У Пионера Мини 2 два «места», где живут программы: <strong>бортовой компьютер</strong> (вычислительный модуль под управлением Pioneer OS) и <strong>ваш компьютер</strong>, подключённый к коптеру по Wi-Fi. Один и тот же скрипт на Python часто можно запустить в любом из них — выбор зависит от задачи: обучение, отладка или автономный полёт.</p>

<div class="grid cards">
<div class="card"><h3>1. На борту: Pioneer Code (CodeOss)</h3><p>Редактор CodeOss работает прямо на борту. Пишете файл <code>.py</code> и запускаете его во встроенном терминале — код выполняется на коптере.</p></div>
<div class="card"><h3>2. На борту: SSH-терминал</h3><p>Подключаетесь к бортовой Linux-системе и запускаете скрипт из консоли. Удобно для отладки и управления файлами.</p></div>
<div class="card"><h3>3. С ноутбука: pioneer_sdk2</h3><p>Скрипт выполняется на вашем компьютере, а библиотека <code>pioneer_sdk2</code> отправляет коптеру команды по Wi-Fi. Классический вариант для обучения и проектов.</p></div>
<div class="card"><h3>4. VS Code на компьютере</h3><p>Пишете код в привычной среде на компьютере и переносите его на борт (копированием или <code>scp</code>) — полезно для большой кодовой базы.</p></div>
</div>

<h2 id="connect">Подключение — общая база для всех способов</h2>
<p>Независимо от способа запуска первым шагом всегда будет подключение к коптеру:</p>
<ol>
<li>Подключите компьютер к Wi-Fi точке доступа <strong>PMINI2</strong>, пароль <code>geoscan123</code>.</li>
<li>Коптер в этой сети получит адрес <code>10.42.0.1</code>.</li>
<li>Проверьте соединение, открыв в браузере <a href="http://10.42.0.1:9090/" target="_blank" rel="noopener">http://10.42.0.1:9090/</a> — должен открыться портал Pioneer Code.</li>
</ol>
<p>Подробно об этом — на странице <a href="/02-start/">«Быстрый старт»</a>.</p>

<h2 id="onboard-oss">Способ 1. Pioneer Code и CodeOss (запуск на борту)</h2>
<p>Самый простой способ для занятий: всё работает в браузере, код хранится на борту.</p>
<ol>
<li>Откройте <a href="http://10.42.0.1:9090/" target="_blank" rel="noopener">http://10.42.0.1:9090/</a> — портал Pioneer Code.</li>
<li>Выберите <strong>CodeOss</strong> (порт <code>http://10.42.0.1:2020/</code>) — редактор на базе VS Code.</li>
<li>Создайте файл <code>flight.py</code> и напишите программу на Python.</li>
<li>Запустите её во встроенном терминале CodeOss командой <code>python3 flight.py</code>.</li>
</ol>
<p>Код выполняется на бортовом компьютере: соединение с точкой доступа не рвётся в полёте (пока открыта вкладка), управлять коптером можно даже с планшета.</p>

<h2 id="onboard-ssh">Способ 2. SSH: терминал на борту</h2>
<p>Для отладки и работы «как на настоящем Linux-сервере»:</p>
<ol>
<li>На компьютере откройте терминал и подключитесь: <code>ssh pioneermini@10.42.0.1</code>, пароль <code>geoscan123</code>.</li>
<li>Загрузите свой скрипт, если он был написан на компьютере, командой <code>scp</code>:
<div class="codewrap"><pre><code>scp flight.py pioneermini@10.42.0.1:~/flight.py</code></pre></div></li>
<li>Запустите программу: <code>python3 flight.py</code>.</li>
</ol>
<p>В терминале удобно смотреть логи, запускать системные утилиты и отлаживать. Если в Windows вы ловите ошибку <code>Connection closed by 10.42.0.1 port 22</code>, проверьте, что на коптере включён OpenSSH Server — подробно в <a href="/02-start/">«Быстром старте»</a>.</p>

<h2 id="from-pc">Способ 3. Запуск с ноутбука через pioneer_sdk2</h2>
<p>Скрипт живёт на вашем компьютере, а коптер управляется по сети:</p>
<div class="codewrap"><pre><code data-lang="python"><span class="tok-k">from</span> pioneer_sdk2 <span class="tok-k">import</span> Pioneer   <span class="tok-c"># импортируем класс Pioneer</span>

drone = Pioneer()                  <span class="tok-c"># установка соединения с коптером по Wi-Fi</span>

drone.arm()                        <span class="tok-c"># включаем двигатели</span>
drone.takeoff()                    <span class="tok-c"># взлетаем</span>
drone.land()                       <span class="tok-c"># садимся</span>

drone.close_connection()           <span class="tok-c"># закрываем соединение</span>
</code></pre></div>
<p>Как установить библиотеку и полное описание API — на странице <a href="/05-sdk2/">«Pioneer SDK 2»</a>, готовые скрипты такого типа — в <a href="/09-examples/">«Примерах»</a>.</p>
<p><strong>Особенность:</strong> связь важна. Если ноутбук потеряет Wi-Fi, скрипт не сможет продолжать работу, в отличие от запуска на борту. Для автономных миссий код кладут на борт.</p>

<h2 id="choose">Какой способ выбрать</h2>
<div class="tablewrap"><table>
<thead><tr><th>Ситуация</th><th>Способ</th><th>Почему</th></tr></thead>
<tbody>
<tr><td>Первые уроки, класс, дети</td><td>Pioneer Code / CodeOss</td><td>Всё в браузере, ничего не надо ставить; работает даже с планшета</td></tr>
<tr><td>Отладка или обслуживание коптера на месте</td><td>SSH</td><td>Полноценный доступ к файлам и процессам на борту</td></tr>
<tr><td>Проект с кодовой базой на компьютере, соревнования</td><td>Ноутбук + pioneer_sdk2</td><td>Быстрая правка кода, полный локальный инструментарий, интеграция с OpenCV и др.</td></tr>
<tr><td>Автономный полёт без участия оператора</td><td>Код на борту (CodeOss / SSH)</td><td>Программа не зависит от связи с компьютером</td></tr>
</tbody></table></div>

<h2 id="tips">Практические советы</h2>
<ul>
<li>Держите <strong>копию</strong> программы и на компьютере (например, в Git), и на борту — Wi-Fi точка коптера не всегда стабильна, копия спасёт от потери файла.</li>
<li>Если скрипт запускается с ноутбука — не закрывайте его и не разрывайте Wi-Fi во время полёта: SDK перестанет получать телеметрию и отправлять команды.</li>
<li>Для работы с камерой и нейросетями лучше запускаться на борту — обработка изображения идёт на NPU без задержек сети (подробнее: <a href="/06-rknn/">«Нейросети (RKNN)»</a>).</li>
<li>Перед запуском вне помещения убедитесь, что знаете режим полёта и настройки высоты — подробнее в <a href="/02-start/">«Быстром старте»</a>.</li>
</ul>
