<h1>Роевые полёты</h1>
<p>Групповой полёт — это несколько коптеров, выполняющих согласованную миссию. Пионер Мини 2 для этого подходит: каждый борт — отдельный Linux-компьютер с SDK, а система позиционирования «Геоскан Локус» и UWB позволяют работать в помещении без ГНСС.</p>

<h2 id="concept">Что нужно для роя</h2>
<div class="tablewrap"><table>
<thead><tr><th>Слой</th><th>Задача</th></tr></thead>
<tbody>
<tr><td>Навигация</td><td>Единая система позиционирования для всех бортов (Локус/УЗ, ИК, UWB или ГНСС) — коптеры должны «видеть» одну систему координат</td></tr>
<tr><td>Адресация</td><td>Уникальные адреса и SSID/каналы для каждого коптера, чтобы команды не смешивались</td></tr>
<tr><td>Синхронизация</td><td>Общее время и общий старт: рассинхронизация часов ломает одновременные манёвры</td></tr>
<tr><td>Координация</td><td>Внешний управляющий скрипт или распределённая логика на борту</td></tr>
<tr><td>Безопасность</td><td>Разнесённые зоны, лимиты высоты/скорости, аварийные посадки</td></tr>
</tbody></table></div>

<h2 id="network">Планирование сети</h2>
<ul>
<li>Каждый коптер по умолчанию раздаёт свою сеть <code>PMINI2-…</code>. Для роя удобнее перевести борта в режим клиента и подключить к одному роутеру — тогда у каждого будет предсказуемый IP (см. <a href="/17-network/">Сеть и PioNet</a>).</li>
<li>Разнесите каналы Wi-Fi: работа нескольких точек доступа в одном канале снижает стабильность связи.</li>
<li>Задайте уникальные SSID и пароли при работе через штатные точки доступа.</li>
</ul>

<h2 id="control">Схемы управления</h2>
<div class="tablewrap"><table>
<thead><tr><th>Схема</th><th>Описание</th><th>Плюсы</th></tr></thead>
<tbody>
<tr><td>Централизованная</td><td>Один управляющий компьютер подключается к каждому борту по SDK и рассылает команды</td><td>Простота логики, общий обзор</td></tr>
<tr><td>Распределённая</td><td>На каждом борту своя программа; старт синхронизируется событием или таймером</td><td>Нет единой точки отказа, меньше трафика</td></tr>
</tbody></table></div>
<p>В обоих случаях полезно единое представление координат: миссии задаются в локальной системе навигации, а старт выравнивается по общему сигналу.</p>

<h2 id="example">Набросок централизованного управления</h2>
<div class="codewrap"><pre><code data-lang="python"><span class="tok-k">from</span> pioneer_sdk2 <span class="tok-k">import</span> Pioneer

<span class="tok-c"># адреса бортов в общей сети</span>
ADDRESSES = [<span class="tok-s">"10.42.0.11"</span>, <span class="tok-s">"10.42.0.12"</span>, <span class="tok-s">"10.42.0.13"</span>]

drones = [Pioneer(tcp=f<span class="tok-s">"{addr}:20556"</span>) <span class="tok-k">for</span> addr <span class="tok-k">in</span> ADDRESSES]

<span class="tok-k">try</span>:
    <span class="tok-k">for</span> d <span class="tok-k">in</span> drones:
        d.arm(); d.takeoff()
    <span class="tok-c"># ... согласованный манёвр ...</span>
<span class="tok-k">finally</span>:
    <span class="tok-k">for</span> d <span class="tok-k">in</span> drones:
        d.land(); d.close_connection()
</code></pre></div>
<p>Порт SDK по TCP — <code>20556</code> (<a href="/11-system/">аудит системы</a>). Точный адрес каждого борта зависит от сети; в режиме точки доступа это <code>10.42.0.1</code>, в общей сети — выданный роутером IP.</p>

<h2 id="safety">Безопасность роя</h2>
<ul>
<li>Разносите стартовые точки и траектории, задавайте безопасные высоты эшелонами.</li>
<li>Ограничивайте скорость и время миссии, предусматривайте автопосадку при потере связи.</li>
<li>Проводите первые групповые полёты без нагрузки и на малой высоте.</li>
<li>Заранее определите порядок действий при нештатной ситуации у одного борта.</li>
</ul>
